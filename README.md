# CodeAlpha_SentimentAnalysis
# Customer Voice: Amazon Review Sentiment Analysis

## Project Overview

This project analyzes Amazon customer reviews using Natural Language Processing (NLP) and VADER sentiment analysis. Reviews are classified as positive, negative, or neutral, and visualizations are used to explore patterns in customer feedback.

## Objectives

* Classify customer reviews into three sentiment categories.
* Explore the distribution of sentiment.
* Compare predicted sentiment with star ratings, where available.
* Identify frequently used words in customer reviews.
* Develop practical insights for understanding customer satisfaction.

## Tools and Technologies

* Python
* Pandas and NumPy
* NLTK VADER
* Matplotlib and Seaborn
* Google Colab

## Methodology

1. Load and inspect the review dataset.
2. Clean review text and handle missing values.
3. Calculate VADER compound sentiment scores.
4. Classify reviews as positive, negative, or neutral.
5. Visualize sentiment distribution and rating comparisons.
6. Examine frequently used words and summarize findings.

## Project Files

* `Amazon_Review_Sentiment_Analysis.ipynb` — notebook containing the analysis and code.
* `Amazon_Review_Visualizations.zip` — exported charts.

## Limitations

VADER may misinterpret sarcasm, context, or product-specific expressions. Predicted sentiment may not always agree with star ratings. Findings describe only the dataset analyzed and should not be treated as representative of all Amazon customers.
